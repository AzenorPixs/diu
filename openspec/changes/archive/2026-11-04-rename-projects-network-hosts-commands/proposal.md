# Commandes de gestion hosts explicites

## Why

Rendre explicite la cible hosts dans les commandes de gestion des couples réseau.

## What Changes

Remplacer les commandes `projects system network` sans `hosts` par les commandes `projects system network hosts` ; adapter tous les niveaux d'aide et les messages d'usage. Aucun alias ancien. Code de lot non attribué.
