## Décisions

Les types conseillés sont affichés sans restreindre les types historiques. Les options binaires sont contrôlées à la saisie. La version est obligatoire au format x.y.z existant, sans défaut pour les projets qui n'en ont pas ; la mise à jour propose la version enregistrée. Le fichier de protocole n'est ni requis ni copié lors de la création ou synchronisation ; une copie existante reste intacte. Les autres variables et les traitements OpenSpec/DevOps restent préservés.
