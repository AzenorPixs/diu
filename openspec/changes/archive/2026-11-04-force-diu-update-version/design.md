## Décision

La version explicite est validée comme version Debian acceptée par le mécanisme existant et recherchée exactement dans les releases GitHub publiques paginées, avec tag et nom de paquet correspondants. Les brouillons et préversions restent exclus. Aucun secours Forgejo ne s’applique à ce parcours. La comparaison avec la version locale est ignorée pour installer le paquet, après vérification des métadonnées. Le parcours sans argument et l’alias historique restent inchangés.
