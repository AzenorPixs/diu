# Conception

Les colonnes APT, GitHub et Flatpak affichent leur disponibilité locale par détection des commandes nécessaires ; aucune requête réseau. Les variables logicielles déclarées sont associées explicitement aux moteurs, Codex CLI à GitHub. Les valeurs absentes ou invalides sont signalées comme inconnues. Les noms et valeurs des variables et les secrets ne sont jamais affichés. Les trois chemins d’information utilisent la même fonction.
