# Conception

La copie racine exclut les cinq dossiers visés. Créer ensuite config, output et .cab-tests vides et attribuer le propriétaire prévu dans le parcours existant. Conserver l'appel OpenSpec pour initialiser un dossier vierge ; conserver la génération DevOps. Le nom ancien protocole local ne reçoit plus de traitement particulier à la création. Les erreurs de création des dossiers sont signalées sans prétendre annuler les écritures antérieures.
