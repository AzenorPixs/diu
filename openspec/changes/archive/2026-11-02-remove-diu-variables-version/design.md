# Conception

La variable est retirée du code actif et du résumé final. La déclaration
`DIU_VERSION` reste l’unique source de la version du paquet DIU dans le
résumé. L’affectation historique `VERSION_VARIABLES` continue d’être
supprimée avant le chargement de la configuration et n’est pas transférée.

Les anciennes archives OpenSpec et les commits publiés restent des traces
historiques des versions déjà livrées.
