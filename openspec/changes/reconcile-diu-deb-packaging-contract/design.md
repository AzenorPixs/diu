# Conception

Plan validé : ACSM-DIU-BOOTSTRAP-PACKAGING-20261028-R1.

La source est un enfant direct validé de la racine. Le paquet reste nommé diu. Les tags sont normalisés par retrait de v et validés comme versions Debian ; une seule version distincte est admise. Sans tag, le build emploie la date locale et la release conserve la version du paquet. Staging et rotation restent préservés.

Les fichiers partagés sont amendés séquentiellement. Les tests utilisent seulement des fixtures, sans identifiant ni transport distant réel.
